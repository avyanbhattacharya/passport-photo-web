# Product principles and feature brief

Useful software for ordinary people, private by architecture. Avoid ads, unnecessary accounts and hidden server dependencies. Keep the task straightforward and the result easy to inspect. Local-first does not mean running at any cost on weak devices. Add an unsupported state rather than an unsafe or excessively slow fallback.

Mission and brand belong to the new project: do not automatically reuse Clean Local Tools' domain, organization, analytics IDs, canonical links, verification files or promises that the implementation cannot prove. Choose and document a code/content license before distributing the new project externally.
