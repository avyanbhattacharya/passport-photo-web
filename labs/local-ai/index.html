Local AI Hardware Test Lab

A shareable, no-account hardware test for browser-local AI. It checks whether this browser can use GPU acceleration, applies the model's approved fallback policy, runs a real pretrained model when supported, and creates a report you can copy or download yourself.

🔒 Your files never leave your machine.

Model code and weights may be downloaded from third-party hosting on first use. The image you choose is passed to the model inside this browser and is not uploaded for inference. No test report is submitted automatically.
