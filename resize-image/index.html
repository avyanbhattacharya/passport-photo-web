Resize an image to exact requirements

Set the pixel width and height requested by a website, application form or upload portal. In Fit / Crop mode, move and resize the crop frame independently from image zoom. On a phone, pinch directly on the photo to zoom in or out while keeping the crop frame in place.

Compress an image to KB or MB

Enter a maximum file size and the tool searches for the highest practical image quality that stays under that limit. This is useful for portals that require, for example, a 600 × 600 JPG under 200 KB.

Private by design

The image is decoded and processed with browser image and Canvas APIs on your device. It is not uploaded to Clean Local Tools for processing.
