How the compressor protects quality

The tool starts with the least destructive approach. Best Quality rewrites the PDF structure without intentionally reducing image quality. Balanced and Smallest Size can render pages to compressed images when stronger size reduction is needed.

Target a specific upload limit

Enable Target file size for limits such as 2 MB or 500 KB. The browser tries progressively stronger settings and stops at the highest-quality candidate that reaches the target. Exact size cannot be guaranteed because PDFs vary widely.

Private by design

Your files never leave your machine. Your PDF stays on this device while the smaller copy is created. The page may load helper code from a third-party source, but your file is not sent there for processing.
